# GoOut Score Dashboard

A React dashboard that uses live weather and air-quality data (Open-Meteo) to calculate a 0–100 **"Should I go out?"** score for any city.

> IMAP group project. Work in progress: Part 1 (foundation) is complete.

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:5173
